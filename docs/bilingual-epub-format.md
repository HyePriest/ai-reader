# EnglishReader 双语 EPUB 约定 v1

这是第一版已实现的格式约定。普通 EPUB 结构保持不变，在 XHTML 正文里增加两个属性即可。首版接受 UTF-8 XHTML，使用 OPF spine 顺序作为章节顺序。

## 一句对一句

```html
<p>
  <span data-er-id="s1">The rain began.</span>
  <span data-er-id="s2">Nora opened the book.</span>
</p>
<p data-er-for="s1" lang="zh">雨下起来了。</p>
<p data-er-for="s2" lang="zh">诺拉翻开了书。</p>
```

英文 span 保留在自然段内，阅读器会保留换行、基本粗斜体对应的位置。中文节点作为译文导入，不出现在英文正文中。

## 合译与拆句

```html
<p><span data-er-id="s1">She turned the envelope over.</span>
<span data-er-id="s2">There was no name on the back.</span></p>
<p data-er-for="s1 s2" lang="zh">她把信封翻过来，背面没有署名。</p>
```

`data-er-for` 可用空格列出多个英文 ID。点击任一对应英文范围，都展示该组中文。一个英文 ID 的中文内容也可以包含多个中文句子。

## 约束

- 英文标记在单个章节文件内唯一。不同章节可以重用 `s1`。
- 标记推荐放在 `span`，也可以放在 `p` 上。原生 `id` 在没有 `data-er-id` 时也可作为目标。
- 中文标记用独立 `p` 节点，不能放在英文段落内部。
- 每个中文节点至少指向一个存在的英文标记，内容不能为空。
- 英文范围不得被多个译文组重叠引用；有错误的文件会拒绝导入，并保留现有书架。
- 没有对应中文的英文照常导入，点击后明确显示“这里还没有译文”。
- 译文准备时可以按完整篇章理解，标记仅规定阅读时如何查找，不要求生成时孤立逐句翻译。
- 不自动推断普通中英交替段落之间的关系，也不把两个译本按第 N 句机械配对。

## 给外部制作工具的说明

请制作标准、无 DRM、可重排的 EPUB，保留英文段落。在英文句子外包裹带 `data-er-id` 的 span，为对应中文添加独立的 `p data-er-for`。英文文本及标点应保留，译文允许合句和拆句，关联标记必须准确。尚未准备好的部分保留英文即可。

制作后应检查：标记唯一、所有中文目标存在、无重叠、无遗漏英文，OPF spine 顺序正确。不要仅凭“EPUB 能打开”就认为语义对应正确。

## 可运行样本

- `app/src/main/assets/a-window-in-the-rain.epub`：原创三节体验短篇，第一节中文完整，第二节部分中文，第三节无中文。
- `tools/make_sample.py`：只用 Python 标准库重建样本，输出内容固定。

## 当前在手机上补充中文

1. 打开目标章节，点击英文句子，再点“添加中文”。
2. 默认关联当前句子，也可以打开“按段落选择”，指定起止段落。
3. 粘贴中文，或从 UTF-8 TXT 读取。
4. 查看英文与中文预览后保存。若覆盖已有组，需要勾选确认；被覆盖组会整体解除关联。
5. 当前每次保存建立一个对应组。读取一整章 TXT 不会自动生成逐句对应，应分批配对需要的范围。

整本中文 EPUB 单独导入、自动章节匹配与半自动逐句对齐尚未实现。当前能力是英文 EPUB + 明确标记的双语 EPUB + 局部人工补充，不能把它描述成已经支持任意中英文书自动对齐。
